جُمْلَتي بالصُّوَر – تواصل بروكا
تطبيق تواصل بديل ومعزّز (AAC) يعمل دون إنترنت بعد أول فتح.

ما في هذا المجلد:
- index.html : التطبيق كاملًا
- img/ : الصور الحقيقية
- manifest.webmanifest و sw.js : ملفات التثبيت والعمل دون إنترنت

طريقة النشر (مرة واحدة):
ارفعي محتوى هذا المجلد كما هو إلى أي استضافة مواقع ثابتة تعمل بـ HTTPS
(مثل Render Static Site أو GitHub Pages أو Netlify أو Cloudflare Pages).

طريقة التثبيت على جهاز المريض:
- Android (Chrome): افتحي الرابط ← القائمة ⋮ ← «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
- iPhone/iPad (Safari): افتحي الرابط ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
- الحاسوب (Chrome أو Edge): افتحي الرابط ← أيقونة التثبيت في شريط العنوان.

الخصوصية: الصور العائلية والأسماء والتسجيلات تُحفظ داخل جهاز المريض فقط ولا تُرسل إلى أي خادم.
احفظي نسخة احتياطية من الإعدادات ← «تنزيل نسخة احتياطية» قبل تغيير الجهاز.
